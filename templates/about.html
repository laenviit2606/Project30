About Language Explorer

This student project helps users find published AUSTLANG records by code, main name, or alternative name.

Data source

Data is provided by the Australian Institute of Aboriginal and Torres Strait Islander Studies (AIATSIS).

View the AUSTLANG dataset

Licence

Data preparation and limitations

The program trims whitespace and compares uppercase copies of names. It separates alternative names using the | character. The original CSV is unchanged.

The search returns the first matching record. Multiple records may share a name. Record counts should not be interpreted as counts of distinct languages.

This application explores published records. It does not generate translations or cultural explanations.
